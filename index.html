My Projects

Marck's Barbershop Reservation System.

Marck's Barbershop Reservation System is a web-based appointment booking system developed using HTML, CSS, JavaScript, PHP, and SQL Server. The system allows customers to conveniently schedule barber appointments online, while helping the barbershop manage reservations, customer records, and appointment schedules efficiently. It reduces manual scheduling, simplifies the booking process, and enhances customer service in general.

Technologies Used:

HTML5 CSS3 JavaScript PHP SQL Server

Key Features:

  • Online Appointment Booking
  • Customer Records Management
  • Contact form with validation

LMD Junkshop

LMD Junkshop Management System is a desktop-based application developed using C# to help streamline the daily operations of LMD Junkshop. The system manages customer transactions, recyclable material records, pricing, and sales reports in an organized and efficient manner. It reduces manual record-keeping, improves transaction accuracy, and provides faster access to business information for better decision-making.

Technologies Used:

C#

Key Features:

  • Transaction Management
  • Inventory Tracking
  • Report Generation
